# SAC 网络结构实验计划与接管说明

2026-10-18，用户授权接管四种网络改动的实现、训练、比较与交付。原有实验全部保留。

## 固定协议

- 结构：baseline、layernorm、split、residual、gru。每组只启用一种结构改动，不叠加。
- 第一阶段：五组各 seed 0，从头训练 300000 决策。
- 第二阶段：第一阶段验证最好的改动与 baseline，各补跑 seed 1、300000 决策。
- 选择：第一阶段按最佳验证平均回报选一个改动，平局再看末三次验证均值。第二阶段按两种子的最佳验证平均回报选结构，再交付该结构中验证最好的单模型。
- 若改动没有超过 baseline，交付 baseline 并如实记录未确认改善，不强行宣布改进成功。
- 训练为 lap95、4 个并行环境、batch 128、随机探索 5000、经验池 50000、actor/critic lr 3e-4、目标熵 -3、自动温度、每向量步一次更新，其他参数沿用原 SAC。
- 每 25000 决策在 1000000–1000009 的 10 条赛道验证。没有根据测试集反复选模型。
- 完成选择后，baseline 和入选改动的两个种子各在新赛道 3000000–3000049 测试；选中交付模型录前三条视频。
- 这是有限预算的探索比较；只有入选候选和基线有两个种子，不声称五组均有多种子结论。等样本不等于等计算成本。

## 四种结构

1. LayerNorm：actor/Q 的 256 维视觉特征层及 Q 隐藏层归一化。
2. 分离动作分支：共享视觉特征后，将转向与油门/刹车分为独立隐藏分支；动作范围和分布定义保持一致。
3. 残差 CNN：用两级小型残差视觉编码器替换原 CNN，独立 actor/双 Q 保持不变。
4. GRU：actor 和双 Q 各编码连续 8 个决策的观察历史。以零隐状态重新处理有限窗口，仅最后转移参与 SAC 损失；回放通过独立环境链重建历史，环形覆盖和回合边界不会串轨迹。训练、目标值与评估使用相同窗口协议。没有将不相关的随机帧冒充时序样本。

## 文件与运行

主要代码：`racing/sac_networks.py`、`racing/sac.py`、`racing/sac_experiment.py`。`--sac-arch` 选择结构，`--sac-context` 默认 8，仅 GRU 使用。旧 SAC 检查点默认按 baseline 加载。

真实环境短自检：`runs_sac_arch_smoke_20261018`。长实验输出：`runs_sac_arch_20261018`。长实验从该目录的 frozen_source 冻结源码运行，源码 SHA256 存在 source_manifest.json。进程顺序执行，不抢占并行 GPU 任务；运行期间只阻止空闲自动休眠，不改变电源计划。

`status.json` 为当前任务及子进程，`commands.jsonl` 记录每次完整命令，`logs/` 记录终端输出。断开后重启协调器会跳过已完成任务，并在新 segment 中恢复未完成训练，旧数据保留。若协调器被强制终止后遗留锁，只能在确认 PID 与所有对应训练子进程均已退出后处理锁，避免重复占用 GPU。

运行完成后自动生成 `delivery/model.pt`、`delivery/code/`、`delivery/实验记录.md`、原始记录与验证曲线，以及 `SAC_architecture_delivery.zip`。随后还需检查测试结果、模型重载和交付文件是否齐全，才向用户宣布完成。

## 解释边界

seed 0 的既有百万决策运行不混入此次 30 万决策的公平比较；可作为历史背景。best 是验证集选模，不等于预算终点 last。若重新训练包含恢复段，环境会从新回合开始，报告须保留恢复记录。用户已有测试赛道 2000000–2000049 不参与本次筛选。

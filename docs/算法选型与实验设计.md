# 算法选型与实验设计

## 选型结论

选 **A2C-GAE、PPO-Clip** 两种课程算法，以及 **ICML 2025 的 VPG-repeat-50** 作为近期研究方法。课程清单列的是类别，A2C 属于 Actor-Critic，PPO 属于 Policy Gradient / Actor-Critic，均在允许范围内。

| 方法 | 适用原因（针对本任务的判断） | 局限与比较价值 |
|---|---|---|
| A2C-GAE | 图像 CNN 编码后直接输出三维连续动作；价值基线和 GAE 降低长轨迹策略梯度的方差；多环境同步采样容易实现 | 每批数据仅一次策略/价值更新，样本利用率可能较低；提供简单且成本低的基线 |
| PPO-Clip | 连续随机策略适合转向、油门、刹车；允许重复利用采样批次，限制过大的概率比变化；适合作为实际训练的主基线 | clip 不保证性能单调；多 epoch 增加时间；仍可能局部停滞或退化 |
| VPG-repeat-50 | 在相同 actor-critic 框架内单独增加 critic 拟合，直接检验“价值估计是否是瓶颈”；实现规模和显存需求适合课程项目 | 50 次全批次 critic 更新更贵；视觉表征问题未必能靠重复拟合解决；在该游戏超过 PPO 是待验证假设 |

不是声称它们是 CarRacing 的绝对最优组合，而是在本机预算、可讲解性、2025 顶会出处和公平实验之间做选择。A2C 与近期方法的关系尤其适合做控制变量实验。

## 任务定义

使用 `gymnasium==1.1.1` 的 `CarRacing-v3`、`continuous=True`。原始图像为 96×96 RGB，三个动作分别是方向 `[-1,1]`、油门 `[0,1]`、刹车 `[0,1]`；赛道随 seed 生成。奖励包含逐帧惩罚与首次覆盖道路的奖励，冲出场地会终止。具体接口与终止条件以固定版本源码为准。[官方环境说明](https://gymnasium.farama.org/environments/box2d/car_racing/)

本项目统一处理：整张图转灰度缩放 64×64（保留仪表区域），堆叠最近 4 个决策时刻的图像；每个动作最多保持 4 个原始帧，遇终止立刻停止；1000 个原始帧为回合时间限制。不裁奖励、不加草地惩罚、不提前结束“不进步”回合。训练奖励乘固定 0.1，仅改变数值尺度；报告累加原始 reward。

4 帧堆叠帮助估计运动趋势，但不把部分可观测问题变成严格完全可观测 MDP。动作重复限制了控制频率，是所有方法共有的任务协议，不应把所得分数与其他跳帧设置直接比较。

网络只有图像输入。赛道内部的 `tile_visited_count` 只用于回合结束后的覆盖率统计，不进入网络、不塑形奖励、不辅助选动作。不存在读取隐藏位置控制车辆的“捷径”。

## 近期论文核验

**Tao Wang, Ruipeng Zhang, Sicun Gao. _Improving Value Estimation Critically Enhances Vanilla Policy Gradient_. ICML 2025, PMLR 267:65449–65463.**

- [正式会议出版页](https://proceedings.mlr.press/v267/wang25em.html)
- [2025 年 5 月首发的 arXiv](https://arxiv.org/abs/2505.19247)
- [完整论文](https://arxiv.org/html/2505.19247v1)
- [作者代码](https://github.com/taowang0/value-estimation-vpg)

该方法满足 2025 年发表和顶会要求。论文研究增加价值更新次数的作用，原实验是连续控制基准；**没有由此证明 CarRacing 上的表现**。本项目是方法的视觉驾驶迁移研究，不是对原文 MuJoCo 数字的精确复刻，也不把截至 2026 年所有方法中“最先进”的称号加给它。没有为了追求 2026 标签选尚未核实录用的论文。

### 论文到源码的对应关系

`racing/train.py` 的 `update()` 是三种算法唯一核心分支：

1. 所有方法先用采样时冻结的值预测计算 GAE 和回报目标。
2. A2C：价值 MSE 一次全批次优化，策略 `-mean(log π × advantage)` 一次全批次优化。
3. VPG-repeat：同一目标做 K 次完整 critic 优化，actor 仍只优化一次。默认 K=50。
4. PPO：按 minibatch、多 epoch 优化截断概率比目标，critic 同时独立拟合。

与作者简化单文件实现一致，VPG 的优势和回报目标在多次 critic 更新期间固定；不会每步更新 actor，也不会把“50 个小批次”冒充“50 次全批次价值更新”。本实现通过微批次梯度累积，在显存有限时保留全批次梯度，每完成一个全批次才执行一次 `optimizer.step()`。独立 actor/critic CNN 确保 critic 更新不偷偷修改策略。

### 迁移改动（写论文时必须披露）

| 项目 | 本工程 |
|---|---|
| 观测编码 | 向量 MLP 换成独立双 CNN，图像灰度、缩放、堆叠 |
| 动作边界 | 高斯潜变量经 tanh 再映射到方向/油门/刹车区间；保存潜变量计算似然 |
| 训练参数 | 默认 actor/critic 学习率均 3e-4，4 环境 × 128 步，统一 GAE 0.95 |
| 尺度处理 | 统一 reward×0.1、优势标准化；可用 `--reward-scale 1 --no-normalize-adv` 做敏感性实验 |
| critic 梯度裁剪 | 默认关闭；actor 范数阈值 1 |
| 时间边界 | 真终止不 bootstrap，超时从终止前图像 bootstrap；两者均截断 GAE 轨迹 |

动作的 tanh Jacobian 对给定已采样潜变量的策略梯度不依赖参数，在新旧策略的概率比中抵消。因此本实现用潜变量高斯 log probability。可选熵项是**潜变量高斯熵**，不是压缩后动作熵；默认熵系数为 0，不混淆两者。

## 为什么不把其他课程类别放进主实验

- 表格 Value/Policy Iteration 需要可枚举状态与转移模型，直接处理高维像素不可行。
- 表格 MC/TD 同样受状态空间限制；REINFORCE 可做但长回合方差大，对本机预算不如带价值基线的方法。
- DQN 是 Value Function Methods 合法子类，但只适用离散动作。虽然 CarRacing 支持离散版本，和连续 PPO 混比会引入动作空间差异；若要做 DQN，应让所有方法统一改用离散任务另开实验。
- SAC/TD3 也是适合连续动作的备选，然而像素经验回放、额外网络与调参会扩大实现和内存预算。以 10 万条、4×64×64 uint8 且同时存当前/下一观测估算，仅观测约 3.28 GB 十进制内存，还未计其他数据；16 GB 机器能优化实现但没有必要把问题做复杂。
- 世界模型类方法有研究价值，但预训练、模型训练和额外系统配置不利于当前“可解释、低预算、从零复现”的目标。

这些是基于任务和成本的选型判断，不等于其他算法无法解决该游戏。

## 实验协议

| 维度 | 预设 |
|---|---|
| 初步实验 | 10 万决策/算法，训练 seed=0 |
| 主实验 | 100 万决策/算法/seed，seed=0,1,2；推荐最终 5 seeds |
| 公平采样 | 同预算决策、相同动作重复；额外报告实际原始帧数 |
| 训练地图 | 各 worker 从 `[0,1000000)` 中抽种子，随机数流独立 |
| 验证地图 | 固定 `[1000000,1000010)`；只用验证选权重/超参数 |
| 测试地图 | 固定 `[2000000,2000050)`；各算法完全相同 |
| 推理方式 | 确定性：对高斯均值作同一 tanh 变换；非随机采样 |
| 主比较模型 | 相同决策预算结束时的 last.pt |
| 补充模型 | 验证均分最大的 best.pt，与主表分开 |
| 视频 | 预先指定测试集合前 3 条赛道，不挑最高分 |

尽管使用同一个训练 seed，不同算法在不同时间终止，经历的地图顺序不必逐步相同；公平性靠共同分布、共同预算、独立训练重复和共同测试集，而非声称轨迹完全一致。最后一个采样批次按环境数取整，最多多出 `num_envs-1` 个决策；预设预算均可整除 4。

### 指标解释

主指标为每个训练 seed 在测试赛道上的原始 return 均值，再在训练 seeds 上平均。报告 seed 间标准差、训练 seed bootstrap 95% 区间；不能把 3×50=150 个回合当成 150 次独立训练。3 seeds 的区间不稳，5 seeds 更好；配对差值只对相同训练 seed 配对，未声称严格显著性检验。

辅助指标：环境定义的完赛率、最终 tile 覆盖率、得分≥900 的回合比例、验证曲线 AUC、首次验证均分≥900 的采样量、决策吞吐、实际帧数、训练秒数、峰值张量显存。≥900 是本项目参考阈值，不称作当前版本官方“已解决”认证。

覆盖率达到 95% 不必等同于环境触发完赛；代码结合真实 `terminated` 与 `new_lap/全部tiles` 识别成功，超时不自动算完赛。

图中阴影为训练 seed 间 ±1 标准差，不是置信区间。按时间的曲线只在所有 seed 的共同观测区间插值；不会外推尚未训练到的性能。`value_mse` 是同批 GAE 目标上的拟合误差，不能写成真实价值函数误差；K 越大它可能越小但不一定泛化越好。

### 如何回答“谁更好”

先回答相同样本数的得分与完赛率，再回答相同训练时间内的表现。VPG 更高分但更耗时与 PPO 更快，可能同时成立。若只有单 seed、曲线交叉、区间很宽或普遍未学会，应报告证据不足。样本效率、墙钟效率与最终性能应分开讨论。

调参采用相同候选预算，例如各算法 actor LR∈{1e-4,3e-4,7e-4}，固定 critic LR=3e-4，只用验证评估；额外调参成本单独计。默认值是起点，不是已被 CarRacing 实验验证的最优值。

## 报告可检验的假设

- H1：PPO 在相同决策预算下优于单次更新的 A2C。
- H2：VPG K=50 相比 K=1 改善驾驶回报，并降低 critic 的同批目标拟合误差。
- H3：K 从 10 增加到 50 有收益递减，墙钟成本可能抵消样本收益。
- H4：颜色变化可能破坏依赖视觉外观的策略；OOD 结果另表报告。

任何假设都允许被实验否定。不要把预期写成实验结果。
